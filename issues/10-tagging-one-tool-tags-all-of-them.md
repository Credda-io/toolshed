**Title:** Tagging one tool puts the tag on half the catalogue

Spent an hour tidying tags yesterday and made everything much worse.

I added the tag `carpentry` to the claw hammer. Went back to the shelf browser
and the hand saw had `carpentry` on it as well. So did the spirit level. So did
a load of things I hadn't touched.

Then I added `power` to the cordless drill and the same thing happened again,
except this time it also turned up on entries I created *afterwards*, which is
the part I really don't understand.

The ones that were affected all had `uncategorised` on them, I think. Anything
I'd already given a proper tag to when I first added it seems to have been left
alone.

I've stopped tagging things until someone looks at this.
