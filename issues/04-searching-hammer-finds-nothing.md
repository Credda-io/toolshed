**Title:** Search finds nothing unless I type it exactly like the label

Members keep telling me the shelf browser is empty and then I look over their
shoulder and it's this.

Our labels are written surname-first, so the claw hammer is catalogued as
`Hammer, claw`. If you type **hammer** you get no results. If you type
**Hammer** with the capital you get it straight away.

Same with tags. Everything in the carpentry bin is tagged `Carpentry` and
searching `carpentry` returns nothing.

I always thought search was supposed to not care about that. It doesn't care
if I type `HAMMER` in some other systems.

Reproduced on the desk machine and on my phone, so it's not a browser thing.
